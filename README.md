# NutriVida
Integrantes :
Manuel Mora
Jasmin Valencia
Javier Gongora


Sitio web para una clínica de nutrición ficticia ubicada en Temuco, Chile. Proyecto de la asignatura FullStack 2.

Es un frontend estático (HTML, CSS y JavaScript puro, sin backend ni base de datos) que simula el uso de la plataforma según el tipo de usuario: visitante, paciente, médico y administrador.

## Funcionalidades

- Inicio de sesión con roles simulados (paciente, médico, administrador)
- Vista pública sin sesión (inicio, historia clínica y novedades)
- Gestión de pacientes: listado, ficha de detalle y edición
- Gestión de profesionales (médicos)
- Agendamiento de horas
- Sección de novedades
- Panel administrativo

## Tecnologías

- HTML5 y CSS3
- JavaScript
- [Bootstrap 5.3.8](https://getbootstrap.com/) 

## Estructura del proyecto

```
NutriVida/
├── html/         # Vistas del sitio
├── estilos/      # Hojas de estilo CSS
├── javaScript/   # Lógica de cada vista
└── imagenes/     # Recursos gráficos
```

## Cómo ejecutar

No requiere instalación ni dependencias. Basta con abrir el archivo [html/index.html](html/index.html) en un navegador, o servirlo con cualquier servidor estático (por ejemplo, la extensión Live Server de VSCode).
